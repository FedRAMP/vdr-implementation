# Example Mini-SDRs

These three fictional examples were generated using a Super Intelligence tool for illustrative purposes. They have been
reviewed and tweaked by FedRAMP staff. They exist only to show you what a complete Mini-SDR might look like with a few
different perspectives.

!!! danger "Do not work from these examples or treat them as anything other than a curiosity!"

    FedRAMP generally finds examples extremely dangerous because historically they are turned into effective
    rules by stakeholders - "we HAVE to write two sentences for each rule!" all because the examples have
    two sentences for each rule. Please don't do that. Especially not for these SI-generated examples.

    They really are only intended to help you visualize a complete Mini-SDR, not at all to inspire specific
    work. Please use them cautiously and appropriately.

These three fictional providers answer the same questions for every rule. Their answers describe implementation as of **December 7, 2026**. Each provider’s JSON and CSV files contain the same answers. We kept each rule response to five short sentences or fewer; your responses can be longer.

Choose **Read sample** to read the answers. The summary at the top counts the implementation statuses in that sample.
