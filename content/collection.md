# Information Collection

FedRAMP will collect the following information from each cloud service provider:

1. Status of addressing the Vulnerability Detection and Response rules, in a high-level ruleset implementation record.
2. Status of addressing the Vulnerability Evaluation and Reporting rules, in a high-level ruleset implementation record.
3. Sample Monthly Activity Report with at least 2 examples of each of the following vulnerability types:
  - Accepted
  - Internet-Reachable
  - Non-Internet-Reachable
  - Likely Exploitable
  - Non-Likely Exploitable
  - Known Exploited
  - Partially Mitigated
  - Fully Mitigated
  - Remediated
4. The name and position of the senior security official attesting to the accuracy of the provided information.
5. A Corrective Action Plan (if applicable)



## Addressing Each Rule

You will provide the following about EACH rule:

- Status: One of Fully Implemented, Partially Implemented, Not Implemented, Not Applicable

- Explanation: A short explanation of how the rule is followed or the reason and risk for not following it.

- Risk & Compensation (if not fully implemented): A short set of explanations of the risk of the rule not being followed, how it might affect customers, what mitigations are in place, and what mitigations customers might put in place.

- Completion Target (if not fully implemented): A completion target date and an explanation of the completion plan.

If a rule applies when something happens, explain how you will handle that event even if it has not happened yet.

For a MAY rule, you can explain your choice not to use the option. Optional assurance and feedback can be left blank.

## Publishing Implementation Information

In addition to providing this information to FedRAMP upon request, a VDR Implementation package containing all of this information should be made available to agency customers in either the cloud service provider's USDA Connect folder or their trust center.
